## 📌 Project Overview

How can retail sales data help a business make smarter decisions?

This project explores Blinkit sales data using **Microsoft Power BI** to transform raw data into an interactive, insight-driven dashboard. I performed data cleaning and transformation, refined the data model, developed DAX measures and calculated columns, and designed visualizations to make business performance easier to understand.

The goal was to convert complex data into clear information that can help stakeholders evaluate sales performance, compare product categories, and understand outlet-level trends.
